# Satoshi

`Satoshi-Variable.woff2` is the roman variable cut of **Satoshi** by Indian
Type Foundry, covering weights 300 to 900 in one 42 KB file.

- Source: https://www.fontshare.com/fonts/satoshi
- Licence: ITF Free Font Licence (free for personal and commercial use)
  https://www.fontshare.com/licenses/itf-ffl

It is bundled rather than linked from a CDN for two reasons. The app is
offline-first and portable, so it cannot depend on a network to draw its own
text; and the website makes no third-party request at all, which is awkward to
claim while loading someone else's stylesheet to say it.

Satoshi is the typeface of the ENS design system, which the rest of the look
comes from too.
