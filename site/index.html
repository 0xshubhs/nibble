how it works

Three steps, then forget it exists.

  1. 01 — Install & forget

    No installer, no account

    Mount the .dmg, run the portable .exe, or chmod +x the AppImage. The mouse appears in your menu bar and stays there.

  2. 02 — Turn on a source

    It starts remembering

    Clipboard, or folders you nominate. Everything is chunked and indexed on your own machine — searchable the moment it lands, embedded a beat later.

  3. 03 — Paste one line

    Your AI can search it

    Add the connector to Claude, ChatGPT or anything else that speaks MCP. From then on it looks things up instead of asking you to explain again.

what it does

A memory that stays on your machine.

Words and meaning

Keyword and semantic search are fused, so an exact term still wins and a paraphrase still lands. Below a similarity floor it says no results, instead of returning everything in some order.

Indexed on device

A 23 MB model runs in its own process on your machine. Downloaded once, then it never needs the network again. A cloud key is optional, never required.

Capture you can see

Clipboard and folders today, audio and screen next. Every source has a switch, a count of what it stored, and a global pause. Anything shaped like a password is dropped before it is written.

Reminders that reach you

Real system notifications, not web toasts. Once, hourly, daily, weekdays or weekly — and a 9am daily stays at 9am across a daylight-saving change.

Survives sleep

Timers are re-checked when the machine wakes or the screen unlocks, so something that came due in your bag still reaches you — once, not as a backlog.

Forget, properly

Forget one result, or everything a source ever captured. Compact rewrites the files without it. No account means there is no copy anywhere else to chase.

Locked to this machine

127.0.0.1

Bound to loopback, so nothing off-box can reach it. Every request needs a bearer token, because anything running locally — including a web page you have open — can also talk to localhost. The Origin header is checked for the same reason.

portable by default

You decide where it writes.

The app picks its data folder at launch. On a USB stick or an AppImage it keeps everything beside the binary; installed properly, it uses the normal per-user location.

Portable mode

default on USB

Triggered by the Windows portable build, an AppImage, a --portable flag, or a file named portable next to the executable.

  • ./nibble-data/store.json
  • ./nibble-data/ (cache)

Installed mode

default when installed

The ordinary per-user application folder for each OS, so backups and migration tools pick it up.

  • ~/Library/Application Support/Nibble
  • %APPDATA%\Nibble
  • ~/.config/Nibble

questions

Before you download it.

Does anything actually leave my machine?

With the default settings, no. The embedding model is downloaded once (~23 MB) and then runs locally, the index is two files on your disk, and the connector is bound to 127.0.0.1. There is no account and no server to sync to. If you switch the embedder to Gemini or Voyage in Settings, then your text does go to them — that is the trade, and it is off by default.

How is this different from just pasting context into the chat?

You do not have to remember what to paste. Your assistant searches the memory itself, as a tool, when the question calls for it — including things you copied weeks ago and forgot you had.

What stops it from storing my passwords?

The clipboard source drops anything matching a known credential shape — private keys, API tokens, JWTs, card-shaped digit runs — plus anything that looks like a high-entropy random string. It is biased towards throwing away something harmless rather than storing a secret. It is a safety net, not a guarantee, which is why Forget is on every result.

Can it record my meetings and my screen?

Not yet, and it says so in the app rather than implying otherwise. Audio is the next phase and screen capture the one after. When they land they get a visible indicator whenever they are running, a one-click pause, and frames that are read and discarded rather than stored — screen capture in particular, because Windows and Linux do not gate it behind any OS permission at all.

Why is the download about 160 MB?

It ships a browser engine and a machine-learning runtime. That is the trade for one codebase producing a native-feeling app on all three platforms, with on-device search, and no runtime to install first.

macOS says it is from an unidentified developer.

The public builds are ad-hoc signed, not Developer ID signed — that needs a paid Apple account. Right-click the app and choose Open, or allow it once under System Settings → Privacy & Security. Adding a certificate to the CI secrets makes the warning go away for everyone.

Can I run it on a machine I do not own?

That is what the portable builds are for. No installer, no admin rights, no registry writes — the memory, the model and the index all live in a folder beside the executable. Take the folder with you and the machine is as you found it.

Can I build it myself?

Clone the repo, npm install, then npm run build:mac, build:win or build:linux. Each target builds natively, so use the CI workflow if you need all three from one machine.
